# 候选人筛选标准（人力资源管培生方向）

## 硬性条件（必须全部满足）

1. **27届**：`geekWorkYear.includes('27')`
2. **非留学生**：教育经历中不能有海外院校
   - 排除关键词：伦敦、新加坡、香港、UCLA、多伦多、海外、留学、英国、美国、澳洲、加拿大
3. **招聘实习≥2段**：`geekWorks` 中至少2段工作经历包含"招聘/简历/面试"相关内容

## 加分项（有更好，不强制）

1. **产研岗位招聘经验**：工作描述中包含"产研/技术/研发/工程师/开发/产品/算法/大模型"
2. **谈薪经验**：工作描述中包含"谈薪/薪酬/offer/薪资谈判"

## 重要判断逻辑

### 大厂背景不是加分项

- 大厂分工细，可能只做sourcing不做谈薪，经验有欠缺
- 开源依赖人才库，不一定能独立开源
- 小厂/创业公司的人反而可能从sourcing到谈薪全流程，更契合

### 什么是"好的招聘经验"

| 好 | 不好 |
|----|------|
| 独立从0到1完成一个岗位的招聘 | 只负责简历筛选，不负责面试 |
| 参与谈薪和offer沟通 | 只负责发JD和收简历 |
| 有产研岗位招聘经验 | 只招销售/客服等通用岗位 |
| 小厂全流程 | 大厂螺丝钉 |

## 反爬策略

- 打招呼间隔随机2-5秒，不要固定间隔
- 每天打招呼不超过200个
- 不要一次性打太多，分批次

## 字段陷阱（踩过的坑）

1. `geekDesc` 是对象不是字符串，内容在 `geekDesc.content`
2. `geekWorks` / `geekEdus` 不是空数组，包含完整数据
3. 教育经历字段是 `school` 不是 `schoolName`，是 `major` 不是 `majorName`
4. 推荐列表是动态的，每次请求返回的人选和顺序都不同
